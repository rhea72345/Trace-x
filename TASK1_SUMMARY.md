## Required Setup for Production

1. **Get Groq API Key**: Sign up at https://console.groq.com/ and get free API key
2. **Set Supabase Secret**: Run `supabase secrets set GROQ_API_KEY=your_key_here`
3. **Deploy Edge Function**: Run `supabase functions deploy ai-investigation`
